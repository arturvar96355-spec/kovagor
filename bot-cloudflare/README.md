# Бот-посредник на Cloudflare Workers (без сервера)

Клиент открывает бота, нажимает «Старт» и подтверждает согласие → бот создаёт для него тему в вашей группе. Вы отвечаете в теме, бот отправляет ответ клиенту от своего имени. Сообщение, начатое с точки (`.заметка`), клиенту не уходит.

Ограничение Telegram: бот не может написать человеку первым, пока тот не нажал «Старт». Поэтому клиенту нужно дать ссылку `https://t.me/ИМЯ_БОТА`.

## Запуск (около 10 минут, карта не нужна)
1. **Бот:** в Telegram у @BotFather — `/newbot`, сохраните токен (никому не пересылайте).
2. **Группа менеджеров:** создайте группу → в настройках включите «Темы» → добавьте бота администратором с правом «Управление темами». Узнать id группы: добавьте в неё бота @getidsbot (id вида `-100…`), потом удалите его.
3. **Cloudflare** (cloudflare.com, регистрация без карты):
   - Workers & Pages → Create → Create Worker → имя `kovagor-bot` → Deploy → Edit code → вставьте `bot-cloudflare/worker.js` → Deploy.
   - Storage & Databases → KV → Create namespace `kovagor-bot-kv`. В Worker: Settings → Bindings → Add → KV namespace → имя переменной **KV**, выберите созданное.
   - Settings → Variables and Secrets: `BOT_TOKEN` (Secret), `WEBHOOK_SECRET` (Secret, любая случайная строка из латиницы и цифр), `GROUP_ID` (Text), `CONSENT_URL` (Text, необязательно).
4. **Подключить вебхук:** откройте в браузере `https://kovagor-bot.ИМЯ.workers.dev/setup?secret=ВАШ_WEBHOOK_SECRET` — должно вернуться `"ok": true`.
5. **Проверка:** напишите боту `/start` с другого аккаунта → «Согласен(на)» → отправьте сообщение → в группе появится тема. Ответьте в теме — сообщение придёт клиенту.

## Заметки
- Согласие хранится в KV вместе с временем. Текст согласия — страница `/consent` на сайте (`CONSENT_URL`).
- Бесплатный тариф Cloudflare: 100 000 запросов в сутки, для заявок этого более чем достаточно.
- Если `workers.dev` не открывается у вас (но Telegram до него дойдёт): настройка `/setup` делается один раз через любой VPN либо из телефона по мобильному интернету.

## Заявка с сайта
Форма на сайте (тариф, имя, контакт, комментарий, итог «Подбора тарифа» + согласие) отправляется на наш сервер и сохраняется там. После отправки клиента перенаправляет в бота по ссылке `https://t.me/kovagor_bot?start=lead_<номер>_<подпись>`. Когда клиент нажимает «Старт», бот забирает карточку заявки с сайта и кладёт её в тему группы: имя, контакт, тариф, подбор, комментарий. Согласие уже дано в форме, поэтому повторно бот его не просит. Клиенту бот отвечает «Заявка получена».

Что нужно настроить:
1. На сервере: `bash scripts/set-lead-secret.sh` — создаёт секрет и показывает значения.
2. В Cloudflare у Worker добавить `PULL_SECRET` (Secret) и `SITE_URL` (Text, `https://kovagor.ru`).
3. На сервере: `bash scripts/deploy.sh`.

Если сайт недоступен для бота или ссылка устарела, бот просто просит согласие и работает как обычный чат. При обновлении кода Worker вставьте новый `worker.js` и нажмите Deploy; переменные и KV остаются.
