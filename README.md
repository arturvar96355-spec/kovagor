# KOVAGOR — сайт студии

Эталонный сайт студии «под ключ»: привлечение заявок, тарифы, портфолио и витрина анимаций (GSAP, Lenis, Motion, WebGL-монограмма на React Three Fiber).

## Запуск
```bash
pnpm install
pnpm dev                 # http://localhost:3000
pnpm typecheck && pnpm lint && pnpm test
pnpm build && pnpm start -p 3111 && pnpm smoke   # дымовая проверка desktop/tablet/mobile
```

## Что нужно от владельца (в тексте сайта помечено `TODO(content)` / `TODO(legal)`)
`grep -rn "TODO(" src` — полный список. Реквизиты — в одном файле `src/content/legal.ts`. Главное: состав тарифов, согласие клиентов на кейсы и их скриншоты/цифры, реквизиты и тексты юридических страниц, контакты (Telegram/email), подтверждение условий из FAQ (договор, права на сайт, правки).
